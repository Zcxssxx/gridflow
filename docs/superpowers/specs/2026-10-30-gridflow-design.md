# GridFlow 设计规格

日期：2026-10-30

## 目标用户与场景

首版面向电力系统课程中的学生和教师、研究者，以及希望把 MoonBit 计算模块嵌入原生程序或 WebAssembly 教学/研究工具的开发者。用户提供稳态输电网算例，查看节点电压、线路潮流、网损和收敛诊断。项目不声称可用于调度、保护、实时控制或生产电网安全决策。

## 交付物

1. 一个以 MoonBit 实现的可复用 AC 潮流库。
2. 一个本地 CLI，可读取受限 MATPOWER case M-file 子集（只解析数据矩阵，不执行 M 代码），输出文本报告或 JSON。
3. 可复现的示例输入和结果；验证将区分自制网络、公开算例输入、以及独立参考求解器产生的结果。
4. README、数据与代码来源说明、Apache-2.0 许可证和 CI。

## 首版支持范围

- 单相正序、平衡交流输电网的稳态功率潮流。
- PQ、PV、Slack 节点，机组出力与负荷，线路串联阻抗和充电电纳，节点并联导纳，变压器非标变比与相移，线路/机组投运状态。
- 极坐标形式全牛顿-拉夫逊法，功率不平衡收敛判据，雅可比矩阵和稠密部分主元线性求解。
- 汇总机组无功出力；提供可选 PV 无功限值处理及 PV→PQ 转换。
- 输出节点电压幅值/角度、线路两端 P/Q、线路有功损耗、迭代次数和收敛状态。
- 对重复/缺失节点、无 Slack 节点、多 Slack 节点、孤岛、不合法参数、奇异雅可比和未收敛返回明确错误或诊断，不静默返回貌似有效的答案。
- CLI 安全读取文件；MATPOWER M-file 只允许已知赋值与数值矩阵语法，拒绝任意函数调用/表达式。

## 暂不支持

最优潮流、短路、动态稳定性、三相不平衡配电网、控制保护逻辑、调度/实时运行、自动修正网络数据、通用 MATLAB 解释器、稀疏矩阵优化、CGMES/PSSE 全格式导入。

## 数据与参考结果原则

IEEE/PSTCA 算例是行业常见测试输入，不视作无错误或唯一官方解。UW 档案提醒 14 节点与 30 节点材料未经过潮流结果核验，30 节点线路阻抗可能有误，118 节点也有估算字段；MATPOWER case 文件也不自动受 MATPOWER 代码的 BSD 许可覆盖。仓库只包含许可状态明确的数据或自行生成的小型算例。外部案例的版本、URL、SHA-256、导入变换、MATPOWER 版本、潮流选项、参考输出和许可证状态应逐项记录。比较参考解时同时检查电压误差和功率残差。

## 质量目标

- 所有公开库 API 有文档，错误可追踪且不会把不收敛误报为成功。
- 自制小型网络有解析/功率平衡测试；标准网络若完成授权和独立参考生成，则用固定版本和固定选项做数值回归。
- 文档中的命令可在当前稳定 MoonBit 工具链重放；CLI 无需 Python、MATLAB 或 Octave 才可求解。
- 公开声明只描述已验证的网络模型和平台，不宣传工业级或保护级用途。
